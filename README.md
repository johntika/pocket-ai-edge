# 🧠 Pocket AI Edge — Sovereign 100% Offline On-Device AI Studio
## Developer & Copyright Owner: Noorma M Hidayat (Johntika Labs & Kenawa Research)

**Pocket AI Edge** adalah aplikasi riset kecerdasan buatan on-device mandiri 100% offline (Air-gap Sovereign AI) yang dioptimasi khusus untuk akselerasi perangkat keras mobile **ARM Mali GPU & Multi-Core CPU**.

---

### 🌟 Fitur Utama:
1. **100% Offline Murni (Air-gap)**: Berjalan penuh tanpa koneksi internet atau server eksternal. Privasi dan kedaulatan data terjaga mutlak.
2. **Akselerasi Perangkat Keras Dual-Mode**:
   - **⚡ GPU Mali-G76**: Menembus hingga ~4.0 tok/s pada bobot model kuantisasi GGUF.
   - **💻 CPU 6-Core**: Mode cadangan hemat daya saat GPU dialokasikan untuk tugas lain.
3. **Model Hub Multi-Brain**:
   - Google Gemma 2 (2.6B Instruct)
   - Qwen 2.5 3B Abliterated
   - ArliAI RPMax 3.8B (Narrative & Story Specialist)
   - Llama 3.2 3B Instruct
4. **Thermal Watchdog & Emergency Memory Release**:
   - Tombol instan untuk mematikan engine komputasi dan melepaskan ~4.1 GB RAM ke sistem operasi dalam hitungan milidetik guna mendinginkan prosesor ponsel.
